Our Vision

Build an AI-native co-design system that moves from model and deployment constraints to workload-specific accelerator architectures.

Treat RTL generation, verification, synthesis, place-and-route, and later board measurements as one evidence ladder rather than disconnected demos.

Use physical implementation feedback to improve the next design decision instead of evaluating it only after the search is over.

Our Values

Stay true to the evidence and the mission.

  • 01
    Scientific discipline

    Analytical, synthesized, routed, and future board-measured claims remain explicitly separated.

  • 02
    Physical feedback

    Implementation effects are part of the search problem, not noise to hide after architecture selection.

  • 03
    Reproducibility

    Experiments, frozen outputs, scripts, and reports live with the code so results can be inspected.

  • 04
    Iteration

    Negative results and target-specific effects feed directly into the next experiment.

Our Team

Research, architecture, RTL, and physical design in one loop.

Kernellum is intentionally small and research-led. The current work spans architecture search, hardware generation, verification, FPGA implementation, physical-design modelling, and experiment design.

The long-term direction is workload-specific accelerator IP whose predicted advantages survive progressively more physical validation.
