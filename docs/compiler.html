Kernellum Compiler

Model in. Architecture out.

A research compiler for exploring how neural workloads and deployment constraints can drive specialized accelerator generation.

Current scope

v0.1: complete dense INT8 model-to-RTL prototype.

model / ONNX subset ↓ validated graph ↓ hardware IR ↓ calibration + INT8 representation ↓ latency / architecture constraints ↓ parallelism search ↓ SystemVerilog + memories + golden vectors ↓ cycle model + RTL simulation ↓ Yosys synthesis ↓ physical FPGA ← next evidence target
v0.1 evidence

Small, complete, inspectable.

The first workload is a 64→32→16→10 classifier. The compiler path selects a four-lane architecture under the modeled latency target and emits the RTL and memory files used by CI.

v0.2 alpha

From topology-specific to graph-driven.

The next compiler path accepts a deliberately narrow ONNX subset, builds an explicit hardware IR and rejects unsupported structures instead of silently pretending to compile them.

SUPPORTED DIRECTION

Graph → hardware IR

Dense-network graph validation, tensor metadata, operator lowering, calibration, quantization parameters and architecture-search inputs.

NOT CLAIMED YET

Arbitrary ONNX / ASIC readiness

No claim of arbitrary operator coverage, production compiler maturity, post-route timing closure, measured power, or manufacturable silicon.

Reproduce

Run the build.

The repository carries the source, generated artifacts, tests and CI workflow.

pip install -e '.[test,onnx]' pytest -q python -m kernellum --out artifacts/digits_int8 bash scripts/run_eda.sh bash scripts/run_ecp5.sh
