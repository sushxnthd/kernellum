v0.2 alpha

The next compiler slice adds a real ONNX front-end for a deliberately narrow sequential dense-network subset, lowers it into an explicit hardware IR, quantizes from calibration data, runs architecture search, emits RTL, and carries a named ECP5-85F target profile for FPGA-family mapping.

ONNX → validated graph subset → hardware IR → calibration + INT8 → architecture search → RTL + golden vectors → ECP5-85F family synthesis → later: place-and-route + board measurement

The alpha front-end is intentionally explicit about unsupported operators rather than silently approximating arbitrary ONNX graphs.
