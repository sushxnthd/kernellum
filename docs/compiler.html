v0.2 alpha

The new compiler path accepts a real ONNX model for a deliberately narrow sequential dense-network subset, lowers it into an explicit hardware IR, derives INT8 parameters from calibration data, searches architecture parallelism, and emits RTL plus golden vectors. CI then simulates and synthesizes that generated RTL.

ONNX → validated Gemm/ReLU subset → hardware IR → calibration + INT8 → architecture search → generated RTL + vectors → Icarus simulation → generic + ECP5-family Yosys synthesis → next: place-and-route + board measurement

Unsupported graph structures are rejected explicitly; v0.2 alpha does not claim arbitrary ONNX support.
