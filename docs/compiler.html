01
HARDWARE IR

Make the graph hardware-readable.

Tensors, operators and shapes become explicit compiler objects rather than opaque framework calls.

02
ARCHITECTURE SEARCH

Search under constraints.

Candidate parallelism is evaluated against modeled latency and hardware cost. Four MAC lanes are the smallest candidate meeting the 10 μs target in the current model.

03
RTL GENERATION

Turn the selected design into inspectable RTL.

Emit SystemVerilog, quantized memories and golden vectors instead of hiding the result behind an API.

04
SELECTED ACCELERATOR

The output is a machine.

The current prototype resolves to a 4-lane INT8 dense accelerator and a reproducible verification path.
