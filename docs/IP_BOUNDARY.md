# IP boundary for the K0 stage

K0 contains conventional research infrastructure: an analytical cost model, exhaustive/random/evolutionary search baselines, benchmark workloads and plotting scripts. No claim is made that these components are novel or patentable.

Before K1 introduces potentially differentiating architecture-generation, learned workload representations, design databases, calibration methods or reusable accelerator blocks:

1. record invention dates and contributors;
2. separate public benchmark/harness code from private experimental code;
3. review potentially patentable material before public disclosure;
4. track background IP from third-party tools, university collaborators, grants and sponsors;
5. avoid granting broad foreground-IP or exclusivity rights without review.

No open-source license is attached at the K0 reset point. A deliberate license can be added later for components Kernellum chooses to open-source.

This note is strategic project hygiene, not legal advice.
