Kernellum Compiler and Physical-Evidence Pipeline

From quantized models to routed architecture search and board-ready validation.

Research record

What this report establishes.

Kernellum couples deterministic model-to-RTL generation with analytical search, synthesis calibration, final-route measurement, bounded physical feedback, and a board-validation handoff. The report organizes those layers as one evidence ladder so architecture decisions can be tested against progressively stronger implementation evidence.
