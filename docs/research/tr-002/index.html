Project SIMILARITY: Learning Routed Timing Laws for Architecture Search

Causal topology intervention, held-out prediction, and route-robust two-candidate selection.

Read PDF ↗Download PDF ↓PDF · 1.04 MB
Research record

What this report establishes.

Project SIMILARITY isolates operand-distribution topology under matched arithmetic fabrics, freezes a differential routed timing law on a discovery corpus, and evaluates it on unseen rectangular geometries and disjoint route seeds. A prospective two-candidate local-transport portfolio then tests whether the learned law can support route-robust architecture selection.
