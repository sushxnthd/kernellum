Closed-Loop Physical-Design Search

Using routed observations to improve workload-specific accelerator choices under a fixed implementation budget.

Read PDF ↗Download PDF ↓PDF · 1.02 MB
Research record

What this report establishes.

K1 tests whether a small set of final-route observations can guide where physical-design budget is spent next. Starting from nine routed designs in a 172-architecture pool, four active acquisitions are compared with an equal-budget random arm. The selection objective is workload latency, not standalone frequency.
