01 / Research program

Three connected problems.

MODEL / COMPILER / SILICON
01 / Hardware IR

Represent model structure for hardware reasoning.

Make tensors, operators, shapes and quantization choices explicit before generation.

02 / Architecture search

Turn deployment limits into design decisions.

Search precision, parallelism, scheduling and memory under latency and resource constraints.

03 / Physical feedback

Let implementation results change the chosen design.

Carry synthesis and place-and-route evidence back into architecture selection.

02 / Working thesis

A useful model-to-hardware compiler should do more than translate. It should expose, search and justify the hardware decisions that matter for the workload.

01

Model constraints

Supported topology, operator coverage and quantization behavior.

02

Deployment constraints

Latency deadline, precision, memory budget, clock target and device family.

03

Architecture decisions

Parallel lanes, buffer structure, scheduling and generated implementation.

04

Evidence

Reference behavior, cycle exactness, RTL simulation, synthesis and physical implementation.
