05 / Origin

Built by Sushanth Dasari.

Kernellum started from a frustration with treating hardware as a fixed box beneath AI. The lab exists to test the opposite idea: what if the model helps specify the machine?

The work is intentionally narrow where it needs to be. Unsupported graphs are rejected. Modeled numbers stay labeled as modeled. Physical claims wait for physical hardware.
