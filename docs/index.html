002 / SYSTEM

A compiler that searches the machine.

The current prototype is deliberately narrow. Supported neural graphs move through a reproducible sequence from model representation to implementation evidence.

01

Lower the workload.

A supported ONNX Gemm/ReLU subset is validated and lowered into an explicit hardware IR. Unsupported structures are rejected instead of silently approximated.

02

Make constraints executable.

Calibration-driven INT8 conversion turns precision and numeric range into compiler artifacts that can be checked against the reference path.

03

Search candidate machines.

The compiler evaluates accelerator configurations against modeled cycles and the target implementation boundary, rather than treating parallelism as a fixed constant.

04

Emit something inspectable.

SystemVerilog, weights and golden vectors are generated together. The output can be simulated, synthesized and traced back to the model-level reference.

05

Let implementation push back.

On the ULX3S-85F reference target, post-route timing rejects cycle-faster candidates that miss the 25 MHz clock. Physical implementation evidence changes the architecture decision.

003 / PHYSICAL FEEDBACK

The fastest design on paper did not win.

KRN-PNR-001 swept 1, 2, 4 and 8 MAC-lane variants against a 25 MHz ULX3S-85F reference target. Place-and-route timing selected the 2-lane implementation.
