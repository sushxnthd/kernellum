Why Kernellum exists
AI hardware should become programmable at the architecture level, not only at the software level.

Kernellum began from a practical question: if a workload has known shapes, precision, latency and memory constraints, how much of the accelerator design process can be generated rather than hand-authored?

Independent by design

Founded by Sushanth Dasari.

I started Kernellum to build at the boundary between machine learning and computer architecture: not another model wrapper, but tools that ask what the hardware itself should look like for a given workload.

The lab is intentionally evidence-first. Modeled values are labeled as modeled. Simulation is labeled as simulation. Physical claims wait for physical hardware.
