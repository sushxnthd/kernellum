01 / Abstract

A compiler that searches the machine.

Most AI tooling optimizes a model for a fixed target. Kernellum asks a different question: which parts of the target can be generated from the model and its constraints?

Today, the work covers a deliberately narrow path from supported dense neural graphs to quantization, hardware IR, architecture search, generated RTL, verification and ECP5 implementation evidence.
