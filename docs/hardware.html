02 / Bring-up sequence

The shortest honest path to physical evidence.

  1. 01
    Select accessible board

    Record exact FPGA device, package, oscillator frequency and programming path.

  2. 02
    Add board constraints

    Clock, reset/button and LED/UART pins in a real LPF file.

  3. 03
    Run place-and-route

    Use the committed run_pnr_ecp5.sh scaffold with explicit device/package/LPF inputs.

  4. 04
    Close timing

    Report achieved Fmax/slack from nextpnr. Do not reuse the 100 MHz modeling assumption.

  5. 05
    Load a bitstream

    Exercise the demo top on the board and verify the predicted digit/result path.

  6. 06
    Measure

    Capture end-to-end inference latency, board power and energy per inference with method notes.
