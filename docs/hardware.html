02 / Bring-up sequence

The shortest honest path to physical evidence.

  1. Freeze the reference target

    ULX3S-85F, CABGA381, 25 MHz and committed LPF constraints.

    Complete
  2. Run the architecture sweep

    Evaluate 1, 2, 4 and 8 MAC-lane variants through board-targeted place-and-route.

    Complete
  3. Select with physical feedback

    Choose 2 lanes at 29.64 MHz. The 4-lane and 8-lane variants miss the 25 MHz target.

    Complete
  4. Package the audited handoff

    Generate the bitstream and checksummed operator tooling in CI.

    Complete
  5. Load a physical board

    Program a compatible ULX3S-85F and verify the inference path on-device.

    Next
  6. Measure

    Capture end-to-end latency, board power and energy per inference with method notes.

    Pending
