02 / Bring-up sequence

The shortest honest path to physical evidence.

  1. 01
    Reference target — complete

    ULX3S-85F · LFE5U-85F-6BG381C · CABGA381 · 25 MHz with committed LPF constraints.

  2. 02
    Architecture sweep — complete

    Run 1/2/4/8 MAC-lane designs through board-targeted place-and-route and record timing/utilization.

  3. 03
    Physical-feedback selection — complete

    Select 2 lanes: 29.64 MHz closes 25 MHz; 4 lanes at 22.12 MHz and 8 lanes at 16.10 MHz do not.

  4. 04
    Bitstream + audited handoff — complete

    Generate the reference bitstream and package it with checksummed operator tooling in CI.

  5. 05
    Load the physical board — next

    Use the KRN-HW-001 kit to program a compatible ULX3S-85F and verify the demo inference path on-device.

  6. 06
    Measure

    Capture end-to-end inference latency, board power and energy per inference with method notes.
